# Quest System

## Model
`quests` kind: `[{title, desc, status: active|done}]`. Maintained by the
background quest extractor (every 6 player turns, transcript + current log
in, revised log out) — quests emerge from play: promises made, jobs taken,
revenge sworn. Active quests fold into every GM envelope ("keep the story
moving toward these").

## Presentation
📜 codex panel, Quests section: ◈ active / ✓ done with descriptions.

## XP
Scene XP via `[[xp delta=… reason=…]]` (25–75 guidance); combat XP is
engine-paid on victory. Level thresholds triangular ×100.

## Finale
A campaign's authored premise/hook drives the GM; "THE END" in narration
triggers the completion card. Parity gaps: the objective chip (current
quest in the banner), quest-complete FX, requesting a finale explicitly,
the complete badge on saves.

## Target-game growth (M4, FutureIdeas)
Journal window with search · quest categories/pinning · GM-authored quest
stages with engine-tracked objectives (the extractor writes; the engine
could verify named objectives against state) · rewards attached to quest
completion via tags.
